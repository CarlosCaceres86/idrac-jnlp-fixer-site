Troubleshooting guide

How to fix viewer.jnlp(...) downloads from Dell iDRAC.

Older Dell PowerEdge systems can append session data to the JNLP filename when you launch the virtual console. This guide explains the filename problem and the small local fix for Chromium browsers.

Quick answer: if your browser downloads a file named viewer.jnlp(…) or jviewer.jnlp(…), the JNLP content may be usable but the filename is no longer the standard .jnlp filename. iDRAC JNLP Fixer changes only that filename during the download.

Why does iDRAC create this filename?

Legacy iDRAC virtual consoles can generate a filename that starts with viewer.jnlp or jviewer.jnlp and then adds session information in parentheses. A browser may save it literally, so an existing Java Web Start or OpenWebStart association does not recognize it as the expected launcher filename.

Downloaded filename

viewer.jnlp(192.0.2.10@0@server,+PowerEdge+R710...)
→

Usable filename

viewer.jnlp

How to fix it in Chrome, Edge or Brave

  1. Install iDRAC JNLP Fixer from the Chrome Web Store. It also works in compatible Chromium browsers such as Microsoft Edge and Brave.
  2. Open your legacy iDRAC interface and choose Launch Virtual Console.
  3. When the browser prepares the download, the extension recognizes the narrow legacy filename pattern and suggests viewer.jnlp or jviewer.jnlp.
  4. Open the resulting file with the Java or OpenWebStart association already configured on your computer.
Important: this fixes the filename only. It does not install Java, launch the console, repair TLS or certificates, bypass browser warnings, or change Java security settings.

Manual workaround

Without the extension, you can usually rename the downloaded file yourself: remove the text after viewer.jnlp or jviewer.jnlp and keep the original file contents unchanged. The extension automates this small step and leaves unrelated downloads alone.

What if the file is renamed but the console still does not open?

That is a separate Java/OpenWebStart or legacy-server compatibility problem. Check that the .jnlp file association is configured, that the browser downloaded the expected file and that the iDRAC is reachable from the management network. Do not weaken TLS or Java security settings just to make an old console run.

For troubleshooting, see the support guide. Include only a redacted filename, browser and operating system; never send credentials, session tokens or a complete license key.

Frequently asked questions

Which iDRAC versions does this target?

The product targets legacy Dell iDRAC downloads that use the viewer.jnlp(...) or jviewer.jnlp(...) pattern. iDRAC6, iDRAC7 and iDRAC8 are the primary compatibility targets; the exact filename produced by a firmware version determines whether it matches.

Does the extension read my server credentials?

No. The filename decision is made locally in the browser. The extension does not inspect JNLP contents, collect browsing history or transmit download data.

Will it rename PDFs or other downloads?

No. The matching rules are deliberately narrow. Ordinary files such as report.pdf, ZIPs and normal JNLP files are left unchanged.
