Support

Separate a filename issue from a legacy Java issue.

The fastest support request includes the browser, operating system and a redacted filename. The extension itself only changes the proposed download name.

Quick checks

Before contacting support.

  1. Confirm the filename starts with viewer.jnlp( or jviewer.jnlp(.
  2. Check that the extension is enabled and the source host is allowed in hosts-only mode.
  3. Open the popup and check the trial counter. After 3 matching renames, activate a lifetime license to keep fixing filenames.
  4. Try a synthetic fixture if you are testing the extension without physical iDRAC hardware.
  5. Check the JNLP association separately with your Java or OpenWebStart setup.

Contact

Send a focused support email.

Include the browser, OS, extension version and redacted before/after filename. You may include the host type, such as “internal IP” or “DNS name”, but do not include credentials.

Email idracjnlpfixer@proton.me
The file was not renamed

Check that the filename has the narrow legacy shape, that the extension is enabled and that the source host is allowed. Ordinary filenames and uncertain patterns are intentionally ignored. If the popup says the trial is finished, the download keeps its original filename until you activate a license.

The file was renamed but Java does not open it

That is outside the extension's scope. Confirm the JNLP association, Java/OpenWebStart installation and the legacy server's TLS/certificate compatibility without weakening security settings.

What should I redact?

Redact real IP addresses, hostnames, usernames, session data, license keys and any server-specific tokens. Synthetic values such as 192.0.2.10 are enough for most reports.
