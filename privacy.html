Privacy

A small extension with a small data footprint.

This policy explains what iDRAC JNLP Fixer processes in the browser, what stays local and what happens when you explicitly activate a license.

Effective date: 6 September 2026

iDRAC JNLP Fixer is an independent browser extension and is not affiliated with Dell Technologies.

Data processed locally

To decide whether a download should be renamed, the extension may process locally in the browser:

  • the tentative download filename;
  • the download URL, final URL and referrer supplied by the browser;
  • the host patterns entered by the user in settings.

The extension does not inspect the contents of downloaded files.

No download collection

The developer does not collect, transmit, sell, rent or share this download information. The extension has no runtime developer backend, account system, analytics, advertising SDK, browsing-history API, telemetry or remote code. It does not persist raw filenames, URLs, referrers, observed hosts, credentials, session tokens or a download history.

Local storage

The extension stores settings such as whether it is enabled, the selected mode and configured host patterns in the browser's local extension storage. If a license is activated, it stores the minimum local license state needed to apply the published offline behavior. The browser may remove this data when the extension is uninstalled.

Payments and licenses

The planned lifetime license costs €2.99 and is purchased through Lemon Squeezy, a separately disclosed third-party checkout and licensing provider. The extension does not receive card details or payment credentials. After purchase, a user may enter a license key and explicitly request validation against Lemon Squeezy's License API.

That explicit validation sends the license key and the minimum API parameters required by Lemon Squeezy. It does not send download filenames, URLs, referrers, observed hosts or JNLP contents. The extension does not contact Lemon while processing downloads. See Lemon Squeezy's privacy policy and terms for the provider's processing.

Website hosting

This public information site is hosted by GitHub Pages. GitHub may process technical request data such as IP addresses and security logs under its own policies. The site does not add analytics, advertising pixels, tracking scripts or external font requests. See GitHub's privacy statement.

Security boundaries

The extension only changes the proposed local filename of a matching download. It does not launch Java, install software, weaken TLS, bypass certificate validation or modify Java security settings.

Contact

For privacy questions, deletion requests or support, contact idracjnlpfixer@proton.me.

Changes

If the extension's data practices change, this policy and the relevant store disclosures will be updated before the change is introduced. This page describes the product's technical behavior and is not legal advice.
